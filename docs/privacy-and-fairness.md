# Privacy and fairness

Career Fit is built to help a person prepare for a job application. It should not be used as an automated hiring or rejection system.

## Data handling

- The demo runs on 127.0.0.1 and sends text to the local Python process.
- The repository contains no personal resume, employment record, or hosted profile.
- Users should avoid placing names, contact details, or other sensitive information into examples committed to a public repository.
- Any future hosted deployment needs a separate consent, retention, deletion, access-control, and security design.

## Known limitations

- The v0.1 seed dictionary is small and English-first.
- Exact matching can miss synonyms, spelling variants, and informal experience.
- A missing mention is not proof that a person lacks a skill.
- Transferable evidence is a hypothesis for preparation, not proof of equivalence.
- Job descriptions may encode occupational, institutional, or demographic bias.
- Evidence types and weights are heuristics and have not been calibrated to hiring outcomes.

## Safe use

Use the report to ask:

- What can I demonstrate with a concrete example?
- Which requirement should I learn or practice next?
- Which hard constraint needs verification?
- Which part of my profile is underspecified?

Do not use it to infer protected characteristics, rank candidates for an employer, or make an adverse decision without human review and an appropriate fairness evaluation.
