# Career Fit example

Run from the repository root:

~~~powershell
career-fit analyze --job-file examples\single_job\people_analytics_job.txt --candidate-file examples\single_job\candidate_profile.txt --evidence-file examples\single_job\evidence.json
~~~

The example deliberately leaves SQL and HR data without direct structured evidence. The report should show the difference between a transferable analytical background and proof of the exact tool or domain requirement. The degree and sponsorship language also demonstrates why hard constraints are reported separately.
