# Security

Do not commit API keys, private job text, resumes, personal data, or proprietary model outputs.

Report vulnerabilities through the repository's private
[GitHub security advisory form](https://github.com/JoeDHJ/career-fit/security/advisories/new).
Do not disclose a vulnerability in a public issue. If private vulnerability
reporting is unavailable, contact the repository owner through their GitHub
profile without including exploit details in a public message.
